#README


M6ANIME 🎌

A free anime discovery website I'm building.

Features

- 🔎 Anime search
- 🏠 Popular anime
- 🖼️ Anime posters
- 📖 Anime details
- 📺 Episode information
- 📚 Seasons and related anime
- 🇬🇧 English Sub & Dub information
- 📱 Mobile-friendly design
- 💾 Favorites and watch progress — planned

Data

Anime information and metadata are provided by the Jikan API.

Important

M6ANIME does not host or distribute copyrighted anime episodes. It is intended for anime discovery and links to official viewing options when available.

Status

🚧 Currently in development

More features coming soon.
